# Young Trip

단체 채팅에서 나온 "여기 가자"를 날짜별 시간표와 지도 루트로 바꿔 주는 국내 여행 계획 앱의 프로토타입입니다.

IT희망학교 팀 프로젝트 · 한동관, 최윤재

## 주요 기능

- **여행방**: 여행방을 만들고 초대 링크로 친구를 부릅니다(최대 6명). 로그인 없이 게스트로 바로 시작할 수 있습니다.
- **채팅에서 장소 뽑기**: 그룹 채팅에 나온 장소 이름을 자동으로 찾아 후보에 담습니다.
- **후보 자동 선별**: 하루 활동 시간을 넘으면 제안자가 적은 곳부터 이유와 함께 뺍니다. 뺀 곳은 되돌릴 수 있습니다.
- **시간표와 루트**: 방문 순서를 최적화하고 날짜별 시간표를 만듭니다(도보·자동차).
- **지도**: 순번 핀, 날짜별 루트 선, 스팟 상세를 보여 줍니다. 구글 지도 키가 있으면 구글 지도로 그립니다.
- **여행 중**: 현재 위치를 보여 주고, 도착을 감지하고, 늦어지면 뒤 일정 조정안을 냅니다.
- **기록**: 사진, 자동 일기, 실제 이동 경로를 남깁니다.

## 기술 스택

Expo SDK 57 · React Native 0.86 · TypeScript · zustand · React Navigation · react-native-svg · Google Maps(선택)

## 실행 방법

Node 24가 필요합니다.

```bash
cd test
npm ci
npm run web        # http://localhost:8090
```

휴대폰에서 보려면 `npm start`를 실행하고 Expo Go로 QR 코드를 찍습니다.

키가 하나도 없어도 모든 기능이 예시 데이터로 동작합니다. 예시 여행(경주 2박 3일)을 보려면 `게스트로 시작하기` → 더보기 → 시연 도구 → `시나리오 채우기`를 누릅니다.

## 환경 변수 (선택)

`test/.env.example`을 `test/.env`로 복사한 뒤 값을 넣습니다.

| 변수 | 넣으면 |
| --- | --- |
| `EXPO_PUBLIC_GOOGLE_MAPS_API_KEY` | 지도가 구글 지도로 바뀝니다 |
| `EXPO_PUBLIC_KAKAO_REST_KEY` | 장소 검색과 자동차 경로를 카카오 API로 받습니다 |
| `EXPO_PUBLIC_AI_PROXY_URL` | 장소 추출, 추천, 일기 문장을 AI 프록시로 만듭니다 |
| `EXPO_PUBLIC_SYNC_URL` | 여러 기기가 그룹 동기화 서버로 이어집니다 |

주의: `.env`는 커밋하지 않습니다. `EXPO_PUBLIC_` 값은 앱 번들에 그대로 들어가 누구나 볼 수 있습니다.

## 브랜치 전략 (Git Flow)

| 브랜치 | 용도 |
| --- | --- |
| `main` | 배포용. 직접 push하지 않습니다 |
| `develop` | 개발 통합 브랜치 |
| `feature/<기능>` | `develop`에서 만들어 `develop`으로 머지합니다 |
| `release/<버전>` | 배포 준비. `main`과 `develop`으로 머지합니다 |
| `hotfix/<내용>` | `main` 긴급 수정. `main`과 `develop`으로 머지합니다 |
