## 4. 계약 추가분 A11

계약 전문은 docs/plan.json의 foundation.contracts에 있다. 이번에 바뀐 것은 다음과 같다. 시그니처 동결은 유지했다. 바뀐 시그니처는 replanForDelay 하나이고, 입력에 delayMin을 더하고 반환을 {adjustments}로 줄였다.

- 시각: op.at 도장(stampAt, lastOpAt), 시계 단조 규칙, core/util의 offsetClock과 manualClock, 시나리오 상수 SCENARIO_T0·SCENARIO_LINE_MS·SCENARIO_INVITE_CODE
- 시나리오: demo/scenarioSteps.ts 순서표와 시각 규칙, playScenarioChat은 chat 단계만, runScenario와 seedScenario는 같은 표, 추출 createdAt = at + 등장 순서
- op 의미: validate는 op.at만 쓴다, member/join 판정과 정원, accountLinked, anonymize는 나간 본인도 허용, 탈퇴 초안의 actorId, 방장 isGuest
- 서비스: 영역별 KV 접두사와 색인 키 규칙, kakaoHttp.post, 구간표 coordKey 색인, 지도 route() 호출은 예산 밖, chaos는 테스트 전용
- 지연: WP5 core/live/delay.ts가 ETA와 15분 경계를 맡고 조정안 생성은 주입받는다
- 테스트 경계: 패키지 사이 단언은 tests/integration-*.test.ts
- ui: TxtLayoutStyle, T.chipLine·sub·field, display 수치, onRoseTrack, NON_TEXT_PAIRS, 그림자 허용 목록, 새 디자인 규칙 검사

WP1~WP6 인수 조건, QA 대상, 스텁 목록(scenarioSteps.ts, core/live/delay.ts 추가), 모든 패키지의 mayRead(이 회의록 추가, WP3에 scenarioSteps와 scenario-tuning 추가)도 같이 고쳤다.
