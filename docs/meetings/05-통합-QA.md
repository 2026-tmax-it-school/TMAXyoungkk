## 6. 남은 위험

- 여러 기기 실시간 동기화는 메모리 전용 폴링 서버로만 되고 기기 간으로 확인하지 않았다. 시연은 같은 기기의 '다른 사람으로 합류(시연)'로 한다.
- 실제 네트워크 끊김 감지가 없다. 오프라인은 시연 토글로만 들어간다.
- 압축(프로필 5MB, 사진 10MB)은 판정과 표시만 한다. 결정 31은 네이티브에서 image-picker quality로 실제 압축한다고 적었다.
  그런데 지금은 quality 1 고정이라 네이티브에서도 줄지 않는다. 결정 31을 지키려면 WP6(사진)과 WP1(프로필)의 화면 코드를 바꿔야 한다.
  고르기 전에는 원본 크기를 알 수 없으므로, 방식(고른 뒤 다시 고르게 할지, 처음부터 quality를 낮출지)을 먼저 정해야 한다.
- 카카오 REST 키는 번들에 들어간다. 시연 한정으로만 쓴다.
