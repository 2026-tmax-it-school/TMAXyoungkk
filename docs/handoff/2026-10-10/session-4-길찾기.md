### 카카오맵 리뷰로 고친 것

- 앱 WebView에서 카카오 로고·저작권 링크를 누르면 지도 대신 카카오 웹사이트가 열리던 문제. 바깥 http(s) 이동은 브라우저로 열고, 그 밖의 스킴은 막는다(`kakaoHtml.ts`의 `kakaoNavAction`). 브리지 주소가 아닌 페이지의 메시지는 버린다.
- **앱 WebView 주소가 `https://localhost`로 바뀌었다**(iOS ATS·안드로이드 평문 차단 대비). 카카오 콘솔 JavaScript SDK 도메인에 `https://localhost`가 있어야 한다.
- 트랙패드 핀치(Ctrl+휠) 한 번에 지도가 끝까지 확대되던 문제. 휠 양을 모아 100px마다 한 단계 움직인다(`kakaoScript.ts`의 `wheelZoomStep`).
- 앱 페이지의 'auth' 시한이 SDK 다운로드 시간까지 세던 문제. 스크립트를 받은 뒤부터 잰다.
- 웹 키보드 이동·확대를 구글 지도와 맞췄다.
- 앱 WebView가 다시 불리면(렌더러 재시작) 핀·선·맞춤을 다시 보낸다.

## 지도 내 위치 버튼 (GPS, 세션 4 후반)

사용자 요청 "GPS 기능도 추가하자", 선택 "지도 내 위치 버튼". 워크플로 `wf_f2ab3e35-1fb`(구현 → 리뷰 → 수정, 에이전트 3개) 모두 끝남, 실패 0. 다시 돌리지 않는다.

- 버튼은 11 지도 탭과 27 길찾기의 큰 지도에만 있다(`MapCanvas`의 `locate` 속성). 작은 미리보기 지도에는 없다. 오른쪽 아래, '전체 보기'와 같은 높이에 있어 360px에서도 겹치지 않는다.
- 누를 때마다: 찾는 중(누르면 취소) → 내 위치로 이동(카카오 레벨 3, 파란 점·정확도 원) → 따라가기(5m 넘게 움직이면, 1초에 한 번까지) → 끄기. 지도를 끌거나 확대하거나 '전체 보기'를 누르면 따라가기가 풀린다.
- GPS는 버튼을 누를 때만 켠다. 화면을 떠나거나 앱이 뒤로 가거나 지도가 내려가면 끈다. 여행 진행 중이면 그 위치(시뮬레이터 포함)를 쓰고 GPS를 켜지 않는다. 좌표는 기기 밖으로 보내지 않고, 길찾기 출발·도착도 바꾸지 않는다.
- 권한 거부·위치 없음·12초 안에 못 받음이면 안내 토스트를 띄우고 꺼진다. 웹은 https나 localhost에서만 된다.
- 파일: `src/core/map/locate.ts`(상태 규칙), `src/components/map/useMyLocation.ts`(위치 받기), `parts.tsx`·`MapCanvas.tsx`(버튼·center 전달), 카카오 웹·앱(`kakaoHtml.ts`의 'center' 메시지), 구글 웹·앱, SVG 지도, `MapScreen.tsx`, `DirectionsScreen.tsx`. 테스트 `tests/wp5-my-location.test.ts`(15개). `core/ports.ts`의 `LocationProvider.watch`에 `adaptive` 선택 값이 더해졌다(따라가기 중 갱신 간격).
- 리뷰로 고친 것: 껐다 켜면 예전 위치로 튀던 문제, 기기에서 따라가기가 20m마다만 갱신되던 문제, 처음 맞출 때 내 위치 점이 지도 맞춤에 섞이던 문제.

## 이 세션에서 알게 된 것

- Expo는 서버를 띄울 때만 `.env`를 읽는다. 키를 바꾸면 웹 서버를 다시 띄워야 한다. 서버 시각(`ps -o lstart`)과 `.env` 수정 시각(`stat`)을 비교하면 빨리 안다.
- 카카오 지도가 SVG로 떨어지면 키 값을 보지 말고 `curl -H "Referer: http://localhost:8090/" "https://dapi.kakao.com/v2/maps/sdk.js?autoload=false&appkey=$K"`의 응답 본문을 본다. `disabled OPEN_MAP_AND_LOCAL service`는 그 앱의 카카오맵이 꺼졌다는 뜻이다.
- 앱 안 브라우저 창이 숨겨져 있으면 클릭·스크린샷이 막힌다. 그때는 `javascript_tool`로 요소를 눌러 확인한다. 탭이 여럿이면 `tabId`를 꼭 준다(다른 탭에서 스크립트가 돈 적이 있다).
